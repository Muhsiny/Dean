# EngageFlow AF

Native Android app for managing real engagement goals and reading live metrics from Facebook Pages and Instagram Business accounts through Meta Graph API.

Features:
- Facebook Page follower / page-like metrics
- Instagram Business follower / media metrics
- Facebook post reaction and comment metrics
- Instagram media like and comment metrics
- Numeric growth goals with progress bars
- Dari/Persian smart-reply helper
- Open a Facebook or Instagram post directly from the app
- Meta token and IDs are stored only in Android private app storage

This build does not embed account credentials. The user enters their own Meta access token after installation.
